# 🚀 AI-Powered Agentic Order Management System

A full-stack, enterprise-grade order management application featuring an autonomous AI agent capable of tool-calling, real-time streaming responses, persistent multi-turn memory, and a cross-platform glassmorphism UI.

## 🛠️ Tech Stack
* **Backend:** Java, Spring Boot 3.3.4, Spring AI 1.0.0-M6, Spring WebFlux
* **AI Model:** Google Gemini Flash
* **Database:** MySQL, Spring Data JPA
* **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript, Marked.js, Web Speech API

## ✨ Key Features
* **Autonomous Tool-Calling:** AI agent automatically invokes CRUD tools to check, create, update, or cancel orders directly in the MySQL database.
* **Real-Time Streaming:** Uses Server-Sent Events (SSE) and Reactive WebFlux for word-by-word typewriter effect responses.
* **Persistent Chat Memory:** Context-aware conversations across multi-turn sessions scoped per user.
* **Cross-Platform Responsive UI:** Glassmorphism dashboard optimized for both mobile and desktop screens.
* **Voice-to-Text Integration:** Built-in Speech Recognition allowing users to talk directly to the agent.
